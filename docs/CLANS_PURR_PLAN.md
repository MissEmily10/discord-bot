# Кланы в Purr — план переноса

Решено (26.10.2026): **клан создаёт бот сервера** (сбор впятером, взнос голдой),
**всё остальное внутри клана ведёт Purr**: состав, казна, продление, долг,
биллборд, квесты, магазин, совет. Правила — [CLANS_TODO.md](CLANS_TODO.md),
принципы квестов — [quests/README.md](quests/README.md).

## Сделано

### Связка серверов — `ecosystem.py`
- /eminemovna → Бункер → «Связка серверов» (только создатель бота).
- Сервер-основа + подключённые по коду (10 минут). Данные кланов общие на
  всю связку: `ecosystem.scope(guild_id)` -> id основы.
- Не связанный сервер живёт сам по себе — **пробный сервер** не смешивается
  с основным.

### Реестр кланов — `clans.py`
Как клан попадает в Purr:
1. **Сам** — по сообщению бота сервера о создании клана (embed «Клан [ТЕГ] …
   создан», поля «Глава», «Замы», «Представители»). Нужен `CLAN_SOURCE_BOT_ID`
   (тот же, что для казны), по желанию `CLAN_CREATE_CHANNEL_ID`. Если бот
   сервера сначала пишет «сбор…», а потом меняет сообщение — Purr ловит и правку.
   Подхватил — ставит 🛡️ на сообщение.
2. **Ответом** «@Purr зарегистрируй» на сообщение о создании.
3. **Вручную** (пробный сервер): «@Purr новый клан [ТЕГ] Название @глава @зам
   @зам @пред @пред».
- Роль клана ищется по `[ТЕГ]` в названии роли; участники клана = участники роли.
- «@Purr реестр кланов», «@Purr клан ТЕГ» — карточка: команда, участники, казна.
- ⚠️ Формат сообщения бота сервера о создании угадан — нужен скрин, чтобы
  подогнать разбор (как было с карточкой казны).

### Казна — `clan_treasury.py`
Работает на связку серверов (общая казна).

### Состав — `clan_members.py`, команда `/clan` (для всех)
- Не в клане: список кланов → карточка (команда, сколько человек) →
  «Подать заявку» (пара слов о себе). Заявка — в текстовый канал клана (его
  категория) с кнопками «Принять / Отклонить»; канала нет — главе в ЛС.
  Решают глава, замы, представители; ответ заявителю в ЛС.
- В клане: состав (команда, участники со стажем, свободные места) и кнопки
  по должности: пригласить (глава, замы, представители), исключить (глава —
  любого, зам — только рядовых), команда — назначить/снять 2 замов и
  2 представителей (глава), передать главу (новый глава подтверждает),
  выйти (глава — только после передачи). Каждое действие — вопрос «Да / Нет».
- Админы Purr могут то же, что глава.
- Роль клана выдаёт/снимает Purr. Роль выдали/сняли руками или ботом
  сервера — состав подстраивается сам. Состав с роли берётся один раз
  (при первом открытии клана), дальше — по событиям.
- Глава ушёл с сервера → глава по стажу: зам → представитель → самый
  давний участник; сообщение в канал клана. Зам/представитель ушёл — место
  свободно, главе сообщение. До 50 человек, один клан на человека в связке.
- Кнопки постоянные, повторное нажатие ничего не меняет; заявка без ответа
  неделю — больше не действует.
- Пока нет: напоминание главе раз в сутки о пустом месте в команде,
  анкета-форма вместо «пары слов» (п. 9), список «Всё о кланах» с
  ограничением «через месяц после создания».

### Срок, продление, долг, роспуск — `clan_life.py`
- Срок 30 дней (старым кланам — с первого запуска заново). ЛС главе и замам
  за 3 дня и за 1 день; за сутки — стипендия за квесты (1 → 1000, 2 → 2500,
  3 → 5000, один раз на срок); в день продления: казна × огонёк → −5000
  (или бесплатно — награда месяца).
- Не хватило — долг 7 дней: огонёк сгорает, магазин и приём новых закрыты,
  нет наград месяца и места в Совете, метка «⏳ в долгу»; ЛС каждый день и за
  сутки до роспуска. Долг гасится сам, срок — от прежней даты.
- Роспуск: за долг — сам; главой — с подтверждением зама; админом — из
  панели. Роль, каналы и категория удаляются, казна аннулируется (журнал).
- «Надёжный» — 3 продления подряд без долга. Повторный долг — клан скрыт
  из «Всё о кланах» месяц. Пустые места в команде — главе раз в сутки.
- **Автоматика выключена, пока админ не включит**: /clan → «Управление
  кланами» → «Включить жизнь кланов» (роспуск удаляет роль и каналы).

### Биллборд и огонёк — `clan_billboard.py`
- Войс: минута идёт, если в голосовом канале клана ≥3 и хоть у одного
  включён микрофон. Сообщения — в каналах категории клана. Респект — из
  журнала казны. Баллы с десятыми, остатки не сгорают.
- Неделя — до воскресенья 20:00 МСК: снимок мест навсегда, отчёт недели.
  Огонёк — недели подряд в топ-3 по снимкам.
- Итоги месяца: топ-3 (не в долгу) — выделение роли; 1–2 — бесплатное
  продление; 1 — градиент роли (если сервер умеет) и +10% к наградам в
  казну. Лидеры направлений — значки навсегда. Живая карточка биллборда с
  кнопкой «Лидеры направлений».

### Квесты — `clan_quests.py`
- По одному лёгкому, среднему и сложному на срок из docs/quests (450),
  без повторов; «Сдать квест» → «Принять / Вернуть» в канале проверки с тем,
  что бот видел сам; респект +1 / +3 / +10 в направлении квеста.

### Ивенты — `clan_events.py`
- Анонс (название, время, войс, для кого) → бот сам считает войс → отчёт →
  админ выбирает тип: клановый +1, открытый +3 и +500, большой +6 и +1500.
  Не больше 4 в месяц и одного в день.

### Магазин — `clan_shop.py`
- Покупки — глава и замы, условное списание (казна не уходит в минус).
  Сам выдаёт: цвет роли, доп. каналы, +5 мест (до +10), замену квеста.
  После «Одобрить» админа: название, тег (переносит всё на новый тег), герб,
  эмодзи, стикер, звук. Отклонено — деньги назад. Напоминания 24 ч / 48 ч.

### «Всё о кланах», Совет, управление — `clan_hub.py`
- Живое сообщение со списком кланов и меню → карточка клана: команда,
  участники, казна, огонёк, «чем известен», значки, квесты, статус,
  «Подать заявку», «Респекты подробно». В список — через N дней после
  создания (по умолчанию 30).
- Совет кланов — канал на месяц: представители топ-3 и лидера 🛠; история
  старого — файлом в журнал кланов.
- «Управление кланами» (админы): жизнь кланов, каналы проверки / журнала /
  биллборда, категория Совета, роль дежурных, публикация биллборда и «Всё о
  кланах», направления наград по главам категорий, правка казны / респекта /
  срока с причиной, роспуск.

### Картинки по макетам из Figma — `clan_art.py`
- Карточка клана — картинкой в одном из 10 стилей (`clan.card.1…10`: вино-стекло,
  ночь, салатовый взрыв, наклейки, пудра, небо, бордо-герб, полосы, шашки,
  глитч). Стиль меняют глава и замы: карточка → «Стиль карточки».
- Биллборд недели, «Лидеры направлений», итоги месяца, квесты срока, магазин,
  «Всё о кланах» (`clans.directory`) — картинки с живыми данными; баннер Совета
  (`clans.council.banner`) — в приветствии нового канала Совета.
- Значки (`badge.*`) — PNG из Figma в `panel_art/clans`; дудлы кланов
  (`doodle_clan_*`, `d3_clan_*`) — на кнопках всех клановых панелей.
- Заголовки и цифры — Coolvetica, как в макетах; подписи — Inter.

### Команды
- `/clan` — только для участников: карточка, состав, квесты, ивенты, магазин
  (глава/замы), исключить, команда, выйти.
- `/admin-clan` — администрация: жизнь кланов, каналы, биллборд и «Всё о
  кланах», должности за респект, управление конкретным кланом (казна, респект,
  срок, роль клана, «Панель клана», роспуск).
- Приём в клан — через бота сервера: он выдаёт роль, Purr по выдаче/снятию
  роли ведёт состав. Кнопок «Пригласить» и «Подать заявку» больше нет.
- Роль клана: найдя категорию «ТЕГ · Название», бот пишет в журнал кланов,
  какую роль нашёл («ТЕГ · Название»), и даёт выбрать другую.
- Должности за респект: у главы категории может быть несколько должностей; после
  фиксации награды бот спрашивает его, к какой сфере отнести респект.
