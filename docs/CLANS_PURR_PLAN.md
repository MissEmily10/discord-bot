# Кланы в Purr — план переноса

Решено (26.10.2026): **клан создаёт бот сервера** (сбор впятером, взнос голдой),
**всё остальное внутри клана ведёт Purr**: состав, казна, продление, долг,
биллборд, квесты, магазин, совет. Правила — [CLANS_TODO.md](CLANS_TODO.md),
принципы квестов — [quests/README.md](quests/README.md).

## Сделано

### Связка серверов — `ecosystem.py`
- /eminemovna → Бункер → «Связка серверов» (только создатель бота).
- Сервер-основа + подключённые по коду (10 минут). Данные кланов общие на
  всю связку: `ecosystem.scope(guild_id)` -> id основы.
- Не связанный сервер живёт сам по себе — **пробный сервер** не смешивается
  с основным.

### Реестр кланов — `clans.py`
Как клан попадает в Purr:
1. **Сам** — по сообщению бота сервера о создании клана (embed «Клан [ТЕГ] …
   создан», поля «Глава», «Замы», «Представители»). Нужен `CLAN_SOURCE_BOT_ID`
   (тот же, что для казны), по желанию `CLAN_CREATE_CHANNEL_ID`. Если бот
   сервера сначала пишет «сбор…», а потом меняет сообщение — Purr ловит и правку.
   Подхватил — ставит 🛡️ на сообщение.
2. **Ответом** «@Purr зарегистрируй» на сообщение о создании.
3. **Вручную** (пробный сервер): «@Purr новый клан [ТЕГ] Название @глава @зам
   @зам @пред @пред».
- Роль клана ищется по `[ТЕГ]` в названии роли; участники клана = участники роли.
- «@Purr реестр кланов», «@Purr клан ТЕГ» — карточка: команда, участники, казна.
- ⚠️ Формат сообщения бота сервера о создании угадан — нужен скрин, чтобы
  подогнать разбор (как было с карточкой казны).

### Казна — `clan_treasury.py`
Работает на связку серверов (общая казна).

## Дальше (по порядку)

1. **Состав** — вступление (заявка → глава/замы/представители), выход,
   исключение по правам, передача главы, уход главы с сервера (CLANS_TODO п. 8).
   Роль клана выдаёт/снимает Purr.
2. **Продление, долг, роспуск** — таймеры в базе, уведомления, санкции,
   «Надёжный» (п. 3, 3б). Аукцион (п. 3а).
3. **Биллборд** — войс (≥3, кто-то не замьючен), сообщения, респект; неделя
   до вс 20:00 МСК; огонёк по снимкам; итоги месяца и награды (п. 4, 4а, 5).
4. **Квесты и стипендия** — выдача 1+1+1 на срок, «Сдать квест» → «Принять /
   Вернуть», респект по направлениям, «чем известен» (п. 6, 11).
5. **Магазин** — покупки из казны, выдача сама, проверка админом (п. 7).
6. **«Всё о кланах»** — живая карточка, заявка в клан, Совет кланов (п. 9, 12).
7. **Карточки кланов** по макетам Figma (п. 13).

## Потом — полный перенос (только в заметках)

- **Создание клана в Purr** — сбор впятером, взнос, резерв тега и названия,
  сгорание через час (CLANS_TODO п. 1). Тогда бот сервера не нужен вовсе.
- **Голда через код** — синхронизация личных балансов и `.награды` с ботом
  сервера не через сообщения, а через API/вебхук (вариант из CLANS.md,
  «Голда живёт в другом боте»): удержание голды при создании, приём наград
  в казну без ручного «зафиксируй», сверка раз в сутки.

## Рядом с кланами — сделано (26.10)

- **`/post` — конструктор постов на сайте** (`post_builder.py`, `builder.html`):
  редактор + живой предпросмотр, embed'ы, поля, картинки (загрузка файлом),
  кнопки, отправка от бота или вебхуком, сохранение в Message Build, импорт/
  экспорт JSON. Дальше: новые блоки Discord (Components V2), действия кнопок
  прямо на сайте, расписание.
- **`/post news:<о чём>` — клановая новость** (`news_generator.py`): нейросеть
  пишет разделы и выбирает самый подходящий шаблон баннера (20 шаблонов
  `scripts/render_news.py`) и дудл к каждому разделу; бот рисует баннер с
  заголовком и собирает пост как в примере создателя бота (баннер, разделы
  с трофеем в строке автора и дудлом справа) и открывает его в конструкторе.
  Иконка в строке автора — текст `news.author_icon` (по умолчанию trophy).
