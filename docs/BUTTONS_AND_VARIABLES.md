# Кнопки и переменные: что где меняется

Справка по Message Build (`/embed`), живым картинкам (`/pictures`) и
переменным. Для каждого действия кнопки по шагам: что спрашивается при
настройке, что происходит при нажатии, кто это видит и **что ещё меняется
следом**.

> Короткая шпаргалка
> - Кнопка меняет **только то, что написано в её действии**. Всё остальное
>   («следом») — в таблице в конце.
> - Сообщение Message Build **запоминает числа в момент отправки**. Само
>   оно обновляется только: по событию (счётчик, заявки), по таймеру «Живое
>   обновление» или кнопкой «Обновить отправленные».
> - Живые картинки перерисовываются **сами раз в 10 минут** (если в них есть
>   переменные) и **сразу** — при нажатии кнопки «Счётчик» с их значением.

---

## 1. Как собирается кнопка

`/embed` → Message Build → хаб **«Кнопки»** (или «Список», «Кнопка формы»):

1. **Подпись** кнопки (до 80 символов). Переменные в подписи **не работают**.
2. **Эмодзи**.
3. **Цвет**: синяя / серая / зелёная / красная — или 🔗 **Ссылка** (тогда
   спрашивается только адрес, действия нет).
4. **Действие** — список ниже. В списке видны только действия, которые
   разрешено собирать твоему уровню.
5. **Значение** действия — своё у каждого (или пошаговый мастер, как у
   «Счётчика»).
6. **Сохранить** build. Уже отправленные сообщения подхватят новую кнопку
   только после «Обновить отправленные».

**Каждое нажатие** бот проверяет заново:
- кто нажал — хватает ли его уровня («Жмёт: …» в Бункере);
- кто собрал — не потерял ли создатель право на это действие
  (тогда «Создатель этой кнопки больше не имеет права…»);
- опасное действие — сначала спрашивает «Точно продолжить?»;
- build удалён — «Эта кнопка устарела».

Кнопка читает настройки из build'а **при каждом нажатии**: поменял действие
и сохранил — старые кнопки в каналах уже работают по-новому (даже без
«Обновить отправленные»).

## 2. Действия кнопок

Формат: **собирает / нажимает / подтверждение**.

### 💬 Отправить сообщение — `message.send`
Собирает: участник · Жмёт: участник · без подтверждения
1. Настройка: текст ответа.
2. Нажатие: нажавший **один** видит этот текст (скрытое сообщение).
3. Меняется: **ничего**. В канал ничего не пишется.
4. ⚠️ Переменные (`{user}` и т.п.) здесь **не подставляются**. Нужен ответ с
   переменными — используй «Показать Message Build».

### ✅ Показать подтверждение — `message.confirm`
То же самое, что «Отправить сообщение»: скрытый ответ нажавшему,
отличается только текст по умолчанию.

### ✏️ Редактировать это сообщение — `message.edit`
Собирает: админ · Жмёт: админ · с подтверждением
1. Настройка: ничего не спрашивает.
2. Нажатие → «Точно продолжить?» →
   - сообщение отправлено из Message Build → нажавшему открывается панель
     этого build'а (только автор build'а или админ). **В канале ничего не
     меняется**, пока не нажать там «Обновить отправленные»;
   - обычное сообщение бота → окно «Текст / заголовок / описание», меняет
     **именно это одно сообщение**.

### 📝 Открыть форму — `form.trigger`
Собирает: участник · Жмёт: участник
1. Настройка: ID формы (или хаб «Кнопка формы» → выбрать форму).
2. Нажатие: проверки — форма видна нажавшему, набор открыт, нет его
   заявки на рассмотрении → открывается окно с вопросами.
3. После отправки:
   - в канал проверки приходит карточка заявки с ✅/❌;
   - нажавший видит «заявка отправлена»;
   - **следом** через ~5 сек обновляются отправленные build'ы с
     `{submissions}`, `{pending}`, `{approved}`, `{rejected}`,
     `{last_submission}`;
   - набрался лимит заявок — форма закрывается сама.
4. Решение по заявке (✅/❌) тоже обновляет эти build'ы.
5. ⚠️ Живые картинки и баннер от заявок **сразу не обновляются** — только
   по своему таймеру (картинки раз в 10 мин).

### 🔽 Открыть выбор — `select.trigger`
Собирает: участник · Жмёт: участник
1. Настройка: что выбирать — `role`, `user`, `channel` или `mentionable`.
2. Нажатие: скрыто показывает список Discord, после выбора — «Выбрано: X».
3. Меняется: **ничего** — роль не выдаётся, выбор не сохраняется. Это пока
   «витрина». Выдать роль — действия ниже.

### 🎭 Выдать роль / Снять роль / Выдать или снять — `role.assign` / `role.remove` / `role.toggle`
Собирает: персонал · Жмёт: участник
1. Настройка: роль (ID или @упоминание). Нельзя: @everyone, роли
   интеграций, роли выше бота, роли с опасными правами (их раздаёт только
   владелец), роли выше твоей.
2. Нажатие: те же проверки ещё раз (на создателя кнопки) → роль
   **нажавшему** выдаётся / снимается («выдать или снять» — переключает).
3. Нажавший видит «Роль @X выдана / снята». Пишется в журнал.
4. **Следом**: `{role:…}`, `{role_list:…}` в отправленных build'ах — только
   по таймеру или вручную; в живых картинках — через ≤10 мин.

### 🪝 Отправить через вебхук — `webhook.send`
Собирает: админ · Жмёт: админ · с подтверждением
1. Настройка: ID вебхука, сохранённого на сервере (/eminemovna → Вебхуки).
2. Нажатие → «Точно продолжить?» → окно «Текст сообщения» → сообщение
   уходит через вебхук; @everyone и роли не пингуются.
3. Ссылка вебхука никому не показывается; в экспорт и шаблоны такие кнопки
   не попадают.

### 📄 Показать Message Build — `build.trigger`
Собирает: персонал · Жмёт: участник
1. Настройка: выбрать сохранённый build (кроме самого себя).
2. Нажатие: build показывается **нажавшему одному**, скрыто.
3. Переменные считаются **для нажавшего**: `{user}`, `{user_messages}`,
   `{user_rank}` и т.п. — это единственное место, где они работают.
4. Учитываются «варианты по роли/уровню» build'а.
5. Этот скрытый показ **не обновляется** потом.

### ➡️ Шаг: заменить сообщение — `build.goto`
Как «Показать Message Build», но если нажать **в скрытом** сообщении — то
сообщение **заменяется** новым build'ом (так делаются пошаговые мастера). В
публичном сообщении — просто присылает скрытое.

### 🔄 Обновить отправленные другого build'а — `build.refresh`
Собирает: персонал · Жмёт: участник
1. Настройка: выбрать build (кроме самого себя).
2. Нажатие: все отправленные сообщения того build'а (и его «детей по
   стилю») перерисовываются со свежими переменными.
3. Пауза **30 сек на build для всех**: нажал один — остальные ждут.
4. Нажавший видит «🔄 Обновлено сообщений: N».

### 🔢 Счётчик — `counter.change`
Собирает: персонал · Жмёт: участник
1. Настройка — мастер:
   1. **Новый счётчик** (имя одним словом) или **Существующий…** — список
      счётчиков сервера и чисел из живых картинок (строки рейтингов и
      таблиц, картинки с одним числом), у каждого — где он живёт.
   2. **Что сделать**: прибавить / отнять / поставить число / сбросить в 0.
   3. **Сколько**.
2. Нажатие (пауза 3 сек на человека и счётчик):
   1. меняется **счётчик сервера** с этим именем (нет такого — создаётся с
      0; может уйти в минус);
   2. **живые картинки** — сразу, если имя совпадает (регистр, пробелы и
      знаки не важны) со:
      - строкой рейтинга или таблицы → меняется число в этой строке;
      - подписью числового поля картинки;
      - названием или slash-командой картинки с одним числом / прогрессом;
      - картинка с текстом `{counter:имя}` просто перерисовывается;
   3. **отправленные build'ы** с `{counter:имя}` — через ~5 сек.
3. Ответ:
   - участнику — «Счётчик **имя**: N» (+ сколько картинок обновлено);
   - персоналу и выше — по каждой картинке:
     - 🖼️ обновлена;
     - ⚠️ не опубликована → `/pictures` → картинка → «Опубликовать»;
     - ⚠️ сообщение не найдено (удалили / нет доступа) → опубликуй заново;
     - ℹ️ «ни одна живая картинка не показывает…» — имя ни с чем не совпало.
4. ⚠️ **Число в картинке и счётчик сервера — два разных числа.** Кнопка
   прибавляет к обоим, но если в рейтинге у «Kick» было 10, а счётчика
   `kick` не было, то после «+1» картинка покажет 11, а ответ — «kick: 1».
   Чтобы были одинаковыми — один раз нажми «Поставить число» с нужным
   значением.
5. ⚠️ Правка картинки руками (редактор, её slash-команда) **не меняет**
   счётчик сервера.

## 3. Переменные

Пишутся в тексте: `{имя}` или `{имя:настройка}`. Неизвестная переменная
остаётся как есть. Полный список с примерами — панель **«Переменные»**.

### Где работают
| Место | Работают? |
|---|---|
| Текст сообщения, заголовок, описание, автор, подвал, поля embed'а | ✅ |
| Живая картинка: название, текстовые поля, ячейки таблиц | ✅ (кроме имён в рейтинге) |
| Строки баннера сервера | ✅ |
| Подписи кнопок, пункты списка, ссылки, картинки | ❌ |
| Ответ «Отправить сообщение» / «Подтверждение», текст вебхука, вопросы форм | ❌ |
| «Кто нажал» (`{user}`, `{user_messages}`…) | только в «Показать Message Build» / «Шаг» и в сообщениях триггера «новый участник» |

### Когда обновляются
| Где | Когда |
|---|---|
| Отправленный Message Build | в момент отправки; потом — по событию (`{counter:…}` при нажатии счётчика, заявки), по таймеру «Настройки → Живое обновление» (от 5 мин), кнопкой «Обновить отправленные» / «Обновить отправленные другого build'а» |
| Build с переменными «кто нажал» | **никогда** не обновляется (он у каждого свой) |
| Живая картинка | раз в 10 мин сама; сразу — при нажатии «Счётчика» с её значением, при правке в редакторе |
| Баннер сервера | по своему интервалу (от 10 мин) |

### Группы
- **Сервер**: `{server}`, `{member_count}`, `{members:люди|боты}`, `{bots}`,
  `{online}` (Discord отдаёт примерно, раз в 5 мин), `{boosts}`,
  `{boost_level}`, `{boosters}`, `{server_age}`, `{owner}`, `{channels}`,
  `{roles_count}`, `{emoji_count}`…
- **Участники**: `{newest_member}`, `{newest_members:N}`, `{joined:период}`,
  `{left:период}`, `{growth:период}`, `{random_member}`…
- **Роли**: `{role:роли}`, `{role_list:роль}`, `{role_online}`,
  `{role_in_voice}`…
- **Голосовые**: `{voice}`, `{voice_list}`, `{streaming}`, `{cameras}`,
  `{voice_time_top}`, `{voice_time_leader}`…
- **Сообщения / слова / реакции**: `{messages}`, `{messages_top}`,
  `{active_users}`, `{word_count:слово}`, `{reactions_top}`, `{emoji_top}`…
- **Время**: `{date}`, `{time}`, `{weekday}`, `{days_until:дд.мм}`,
  `{time_until:…}`, `{timestamp:…}`, `{hour_greeting}`…
- **Заявки**: `{submissions}`, `{pending}`, `{approved}`, `{rejected}`,
  `{last_submission}` (можно `:ID формы`).
- **Счётчики и бот**: `{counter:имя}`, `{quote_today}`, `{bot_ping}`…
- **Кто нажал**: `{user}`, `{user_name}`, `{user_messages}`, `{user_rank}`,
  `{user_days}`, `{user_voice_time}`…
- **Случайное**: `{random:a|b|c}`, `{random_number:1-6}`, `{dice}`, `{coin}` —
  новое значение при каждой перерисовке.

Настройки списков: число 1–25 — сколько мест в топе; период — сегодня /
вчера / неделя / месяц / всё; `строка` — в одну строку; каналы и роли по
имени, ID или упоминанию, `-канал` — кроме него.

⚠️ Счёт сообщений, войса, заходов и слов идёт **с момента, как бот начал
их записывать**; слово считается с первого раза, когда его вписали в текст.

## 4. Кнопка → что меняется следом

| Нажали | Меняется сразу | Следом сами | Только по таймеру / вручную |
|---|---|---|---|
| Отправить сообщение / Подтверждение | скрытый ответ | — | — |
| Редактировать сообщение | одно сообщение (или открывается панель build'а) | — | отправленные копии build'а — «Обновить отправленные» |
| Форма | заявка в канал проверки | build'ы с `{submissions}` и т.п. (~5 сек) | живые картинки, баннер |
| Выбор | ничего | — | — |
| Роль | роль у нажавшего | — | `{role…}` в build'ах, картинках, баннере |
| Вебхук | сообщение через вебхук | — | — |
| Показать build / Шаг | скрытый показ нажавшему | — | — |
| Обновить отправленные | все копии выбранного build'а | — | — |
| Счётчик | счётчик сервера + совпавшие живые картинки | build'ы с `{counter:имя}` (~5 сек) | баннер |
