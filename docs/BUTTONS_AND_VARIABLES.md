# Кнопки и переменные: что где меняется

Справка по Message Build (`/embed`), живым картинкам (`/pictures`) и
переменным. Для каждого действия кнопки по шагам: что спрашивается при
настройке, что происходит при нажатии, кто это видит и **что ещё меняется
следом**.

> Короткая шпаргалка
> - Кнопка меняет **только то, что написано в её действии**. Всё остальное
>   («следом») — в таблице в конце.
> - Сообщение Message Build **запоминает числа в момент отправки**. Само
>   оно обновляется только: по событию (счётчик, заявки), по таймеру «Живое
>   обновление» или кнопкой «Обновить отправленные».
> - Живые картинки перерисовываются **сами раз в 10 минут** (если в них есть
>   переменные) и **сразу** — при нажатии кнопки «Счётчик» с их значением.

---

## 1. Как собирается кнопка

`/embed` → Message Build → хаб **«Кнопки»** (или «Список», набор кнопок):

1. **Подпись** кнопки (до 80 символов). Переменные в подписи **не работают**.
2. **Эмодзи**.
3. **Цвет**: синяя / серая / зелёная / красная — или 🔗 **Ссылка** (тогда
   спрашивается только адрес, действия нет).
4. **Что делает кнопка** — список по-русски, у каждого пункта написано, что
   будет при нажатии. Видны только пункты, которые можно твоему уровню.
5. Дальше бот **спрашивает по шагам** (вверху экрана «1/2», «2/2»): ID, форматы
   и ключи вводить не нужно.
6. В списке кнопок видно, что делает каждая: «🎭 выдать или снять @Художник»,
   «💬 сообщение в канал: «Привет…»».
7. **Сохранить** build. Уже отправленные сообщения подхватят новую кнопку
   только после «Обновить отправленные».

**Каждое нажатие** бот проверяет заново:
- кто нажал — хватает ли его уровня («Жмёт: …» в Бункере);
- кто собрал — не потерял ли создатель право на это действие
  (тогда «Создатель этой кнопки больше не имеет права…»);
- опасное действие — сначала спрашивает «Точно продолжить?»;
- build удалён — «Эта кнопка устарела».

Кнопка читает настройки из build'а **при каждом нажатии**: поменял действие
и сохранил — старые кнопки в каналах уже работают по-новому (даже без
«Обновить отправленные»).

## 2. Действия кнопок

Формат: **собирает / нажимает**.

### 💬 Ответить текстом
Собирает: участник · Жмёт: участник
1. **Кому показать?**
   - *Только нажавшему* — скрытое сообщение, видит один он;
   - *В канал всем* — бот пишет в этот канал (один человек — не чаще раза в
     10 сек, @everyone и роли не пингуются);
   - *В личку* — бот пишет нажавшему в ЛС; личка закрыта — покажет скрыто.
2. **Текст.** Работают переменные, в том числе «кто нажал»: `{user}`,
   `{user_days}`, `{counter:очки}`…
3. Меняется: только это сообщение. Ничего не сохраняется.

### 🎭 Роль
Собирает: персонал · Жмёт: участник
1. **Какая роль?** — выбрать в списке. Нельзя: @everyone, роли
   интеграций, выше бота, выше твоей, с опасными правами (только владелец).
2. **Что делать при нажатии?**
   - *Выдать или снять* — переключатель: нет роли — выдаст, есть — снимет;
   - *Только выдать*;
   - *Только снять*.
3. Нажатие: роль меняется **у нажавшего**, он видит «Роль @X выдана / снята»,
   запись в журнал.
4. Если роль с тех пор стала выше создателя кнопки или получила опасные
   права — нажавший видит, что кнопку нужно пересобрать.

### 🏷️ Меню ролей
Собирает: персонал (тот, кому можно «Роль») · Жмёт: участник
1. **Какие роли в меню?** — до 25, с теми же ограничениями.
2. **Сколько можно взять?**
   - *Несколько* — любые из меню;
   - *Только одну* — взял новую, остальные из меню снимаются (цвет ника,
     регион и т.п.).
3. Нажатие кнопки: нажавшему скрыто открывается меню, **его роли уже
   отмечены**. Отметил / снял отметку → роли выдаются / снимаются. Ответ:
   «✅ Выдано… ➖ Снято…».

**То же меню прямо в сообщении** (без кнопки): хаб «Интерактив» → «Меню
ролей» → те же 2 шага. Участник выбирает роль в меню под сообщением — она
выдаётся; выбрал ещё раз — снимается.

### 📝 Открыть форму
Собирает: участник · Жмёт: участник
1. **Какая форма?** — список форм сервера, у каждой видно «набор открыт /
   закрыт».
2. Нажатие: форма видна нажавшему, набор открыт, у него нет заявки на
   рассмотрении → окно с вопросами.
3. После отправки:
   - в канал проверки — карточка заявки с ✅/❌;
   - нажавший видит «заявка отправлена»;
   - **следом** через ~5 сек обновляются отправленные build'ы с
     `{submissions}`, `{pending}`, `{approved}`, `{rejected}`,
     `{last_submission}`;
   - набрался лимит — форма закрывается сама.
4. ⚠️ Живые картинки и баннер от заявок **сразу не обновляются** — только
   по своему таймеру (картинки раз в 10 мин).

### 📄 Показать сообщение
Собирает: персонал · Жмёт: участник
1. **Какой Message Build?** — список сохранённых.
2. **Как показать?**
   - *Отдельным сообщением* — нажавший получает его скрыто;
   - *Шаг мастера* — в скрытом сообщении заменяет его на месте (следующий
     шаг анкеты/инструкции); в обычном — присылает скрыто.
3. Переменные считаются **для нажавшего** (`{user}`, `{user_messages}`,
   `{user_rank}`…). Учитываются «варианты по роли/уровню» build'а.
4. Такой показ потом **не обновляется**.

### 🔄 Обновить сообщения
Собирает: персонал · Жмёт: участник
1. **Чьи отправленные сообщения?** — первым пунктом **«Это же сообщение»**
   (кнопка «🔄 Обновить» под самим сообщением), дальше другие build'ы.
2. Нажатие: все отправленные копии build'а (и его «детей по стилю»)
   перерисовываются со свежими переменными.
3. Пауза **30 сек на build для всех**.
4. Ответ: «🔄 Обновлено: N. Не найдено (удалены): M».

### 🔢 Счётчик
Собирает: персонал · Жмёт: участник
1. **Новый счётчик** (имя) или **Существующий…** — счётчики сервера и
   числа из живых картинок (строки рейтингов и таблиц, картинки с числом),
   у каждого — где он живёт.
2. **Что сделать**: прибавить / отнять / поставить число / сбросить в 0.
3. **Сколько**.
4. Нажатие (пауза 3 сек на человека и счётчик):
   1. меняется **счётчик сервера** (нет — создаётся с 0; может уйти в минус);
   2. **живые картинки** — сразу, если имя совпадает (регистр, пробелы и
      знаки не важны) со строкой рейтинга/таблицы, подписью числового поля,
      названием или slash-командой картинки с числом; картинка с
      `{counter:имя}` перерисовывается;
   3. **отправленные build'ы** с `{counter:имя}` — через ~5 сек.
5. Ответ персоналу — по каждой картинке: обновлена / не опубликована /
   сообщение не найдено / ни одна картинка не показывает это имя.
6. ⚠️ **Число в картинке и счётчик сервера — два разных числа.** Кнопка
   прибавляет к обоим; разошлись — один раз «Поставить число».
7. ⚠️ Правка картинки руками (редактор, её slash-команда) счётчик сервера
   **не меняет**.

### ✏️ Редактировать это сообщение
Собирает: админ · Жмёт: админ · с подтверждением
1. Настраивать нечего: экран объясняет, что будет, — «Добавить кнопку».
2. Нажатие → «Точно продолжить?» →
   - сообщение из Message Build → панель build'а; в канале изменится после
     «Обновить отправленные»;
   - другое сообщение бота → окно «текст / заголовок / описание», меняется
     сразу.

### 🪝 Через вебхук
Собирает: админ · Жмёт: админ · с подтверждением
1. **Какой вебхук?** — сохранённые на сервере, которыми ты управляешь.
2. **Какой текст?**
   - *Спрашивать при нажатии* — нажавший пишет текст в окне;
   - *Заранее заданный* — пишешь сейчас (можно переменные), кнопка
     отправляет его сразу после подтверждения.
3. Сообщение уходит с именем и аватаркой вебхука; @everyone и роли не
   пингуются. Ссылка вебхука никому не показывается, в экспорт и шаблоны
   такие кнопки не попадают.

### Старые кнопки
Кнопки, собранные раньше, работают как прежде: «Подтверждение» = «Ответить
текстом» нажавшему; старый «Выбор роли/участника/канала» только показывает
выбранное — пересобери его как «Меню ролей».

## 3. Переменные

Пишутся в тексте: `{имя}` или `{имя:настройка}`. Неизвестная переменная
остаётся как есть. Полный список с примерами — панель **«Переменные»**.

### Где работают
| Место | Работают? |
|---|---|
| Текст сообщения, заголовок, описание, автор, подвал, поля embed'а | ✅ |
| Живая картинка: название, текстовые поля, ячейки таблиц | ✅ (кроме имён в рейтинге) |
| Строки баннера сервера | ✅ |
| Подписи кнопок, пункты списка, ссылки, картинки | ❌ |
| «Ответить текстом», заранее заданный текст вебхука | ✅ (и «кто нажал») |
| Вопросы форм | ❌ |
| «Кто нажал» (`{user}`, `{user_messages}`…) | в «Ответить текстом», «Показать сообщение» / «Шаг», в сообщениях триггера «новый участник» |

### Когда обновляются
| Где | Когда |
|---|---|
| Отправленный Message Build | в момент отправки; потом — по событию (`{counter:…}` при нажатии счётчика, заявки), по таймеру «Настройки → Живое обновление» (от 5 мин), кнопкой «Обновить отправленные» / «Обновить отправленные другого build'а» |
| Build с переменными «кто нажал» | **никогда** не обновляется (он у каждого свой) |
| Живая картинка | раз в 10 мин сама; сразу — при нажатии «Счётчика» с её значением, при правке в редакторе |
| Баннер сервера | по своему интервалу (от 10 мин) |

### Группы
- **Сервер**: `{server}`, `{member_count}`, `{members:люди|боты}`, `{bots}`,
  `{online}` (Discord отдаёт примерно, раз в 5 мин), `{boosts}`,
  `{boost_level}`, `{boosters}`, `{server_age}`, `{owner}`, `{channels}`,
  `{roles_count}`, `{emoji_count}`…
- **Участники**: `{newest_member}`, `{newest_members:N}`, `{joined:период}`,
  `{left:период}`, `{growth:период}`, `{random_member}`…
- **Роли**: `{role:роли}`, `{role_list:роль}`, `{role_online}`,
  `{role_in_voice}`…
- **Голосовые**: `{voice}`, `{voice_list}`, `{streaming}`, `{cameras}`,
  `{voice_time_top}`, `{voice_time_leader}`…
- **Сообщения / слова / реакции**: `{messages}`, `{messages_top}`,
  `{active_users}`, `{word_count:слово}`, `{reactions_top}`, `{emoji_top}`…
- **Время**: `{date}`, `{time}`, `{weekday}`, `{days_until:дд.мм}`,
  `{time_until:…}`, `{timestamp:…}`, `{hour_greeting}`…
- **Заявки**: `{submissions}`, `{pending}`, `{approved}`, `{rejected}`,
  `{last_submission}` (можно `:ID формы`).
- **Счётчики и бот**: `{counter:имя}`, `{quote_today}`, `{bot_ping}`…
- **Кто нажал**: `{user}`, `{user_name}`, `{user_messages}`, `{user_rank}`,
  `{user_days}`, `{user_voice_time}`…
- **Случайное**: `{random:a|b|c}`, `{random_number:1-6}`, `{dice}`, `{coin}` —
  новое значение при каждой перерисовке.

Настройки списков: число 1–25 — сколько мест в топе; период — сегодня /
вчера / неделя / месяц / всё; `строка` — в одну строку; каналы и роли по
имени, ID или упоминанию, `-канал` — кроме него.

⚠️ Счёт сообщений, войса, заходов и слов идёт **с момента, как бот начал
их записывать**; слово считается с первого раза, когда его вписали в текст.

## 4. Кнопка → что меняется следом

| Нажали | Меняется сразу | Следом сами | Только по таймеру / вручную |
|---|---|---|---|
| Ответить текстом | ответ нажавшему / в канал / в личку | — | — |
| Редактировать сообщение | одно сообщение (или открывается панель build'а) | — | копии build'а — «Обновить отправленные» |
| Форма | заявка в канал проверки | build'ы с `{submissions}` и т.п. (~5 сек) | живые картинки, баннер |
| Роль / Меню ролей | роли у нажавшего | — | `{role…}` в build'ах, картинках, баннере |
| Вебхук | сообщение через вебхук | — | — |
| Показать сообщение / Шаг | скрытый показ нажавшему | — | — |
| Обновить сообщения | все копии выбранного build'а | — | — |
| Счётчик | счётчик сервера + совпавшие живые картинки | build'ы с `{counter:имя}` (~5 сек) | баннер |
