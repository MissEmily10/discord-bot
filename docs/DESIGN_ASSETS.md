# Оформление бота: картинки для панелей

Каждая панель бота — это embed. Картинки встают так:

```
┌──────────────────────────────────────────┐
│                 БАННЕР                   │  ← banner: свой у каждого экрана,
└──────────────────────────────────────────┘    отдельной карточкой НАД текстом
┌──────────────────────────────────────────┐
│ ЗАГОЛОВОК                      ┌──────┐  │
│ Текст панели…                  │ИКОНКА│  │  ← thumbnail: справа сверху
│ Кнопки: …                      └──────┘  │
└──────────────────────────────────────────┘
 [кнопки панели]
```

Discord рисует картинку внутри embed'а только под текстом, поэтому баннер
бот отправляет отдельным embed'ом перед основным.

## Заготовка в Figma

[Discord-бот — оформление панелей](https://www.figma.com/design/oltPivYjeOZWYy40JNYWKp):
все слоты — компоненты нужного размера, названные ключами из веб-панели, с
настроенным экспортом PNG. Сейчас в слотах стоят 3D-версии (слой «3d»), а
прежние рисунки лежат там же скрытыми — включи видимость, чтобы вернуть. Справа от иконок — живой предпросмотр панели в
тёмной и светлой теме Discord. Ниже — баннеры всех экранов, по командам.

## Размеры

| Что | Размер макета | Как показывает Discord | Формат |
|---|---|---|---|
| Иконка (`thumbnail`) | **256 × 256** | до 80 × 80, углы чуть скруглены | PNG с прозрачностью |
| Баннер (`<экран>.banner`) | **1200 × 300** (4:1) | по ширине embed'а, ~400–520 px | анимированный GIF (до ~2 МБ) или PNG |

- Иконка видна мелко: крупный простой силуэт, без мелкого текста и без
  белой обводки (на тёмной теме она выглядит рамкой).
- Важное в баннере держи по центру: на телефоне края смотрятся меньше.
- Discord бывает тёмный (фон embed'а `#2B2D31`) и светлый (`#F2F3F5`).
- Цвет полоски слева у всех панелей — «Основной цвет» в /design или в
  веб-панели. Подбери его под палитру макетов.

## Иконки — по командам

Экран без своей иконки берёт иконку команды, а та — общую.

| Ключ | Где видно |
|---|---|
| `thumbnail.default` | всё, у чего нет своей иконки |
| `thumbnail.embed` | /embed и всё внутри (расписание, триггеры, настройки) |
| `thumbnail.library` | главная /library |
| `thumbnail.templates` | шаблоны в /library |
| `thumbnail.interactive` | главная /interactive |
| `thumbnail.buttons` | наборы кнопок в /interactive |
| `thumbnail.select` | меню ролей в /interactive |
| `thumbnail.forms` | формы в /interactive и /forms |
| `thumbnail.logo` | /logo и стили иконок |
| `thumbnail.eminemovna` | главная /eminemovna |
| `thumbnail.access` | доступ и оформление в /eminemovna |
| `thumbnail.webhooks` | вебхуки в /eminemovna |

Иконки — фирменные смайлики в 3D: `python3 scripts/render_thumbnails.py`
(у каждой команды свой смайлик, как в макете; у library, interactive и
eminemovna — смайлик с предметом команды). Плоские оригиналы, из которых они
сделаны, — `scripts/smiley_originals/`.

Своя иконка экрана (`<экран>.thumbnail`, например `embed.home.thumbnail`)
перекрывает иконку команды. `none` — без иконки.

## Баннеры — главные экраны и автоматические сообщения

Баннер есть у стартового экрана каждой команды, у универсального «доступ
запрещён» и у сообщений, которые бот шлёт сам. На остальных экранах баннеров
нет (и поля для них в веб-панели нет).

| Ключ | Где | Готов |
|---|---|---|
| `access_denied.banner` | любой отказ в доступе, на всех командах | ✅ |
| `embed.home.banner` | `/embed` | ✅ |
| `library.home.banner` | `/library` | ✅ |
| `interactive.home.banner` | `/interactive` | ✅ |
| `forms.review_home.banner` | `/forms` | ✅ |
| `logo.home.banner` | `/logo` | ✅ |
| `eminemovna.home.banner` | `/eminemovna` | ✅ |
| `webhooks.home.banner` | `/webhook` | ✅ |

Баннеры экранов — анимированные GIF в фирменном стиле (стеклянная плашка,
растянутые буквы, 3D-смайлики): `python3 scripts/render_banners.py`, рядом
кладётся PNG первого кадра (он же в Figma). Надпись у каждого экрана своя,
«eminemovna» — только на `/eminemovna`. Скрипт сам проверяет раскладку: текст
не выходит за плашку, смайлики и картинки не наезжают на текст, на три точки
плашки и друг на друга (в каждом кадре) — иначе ошибка и файл не пишется.

Все главные экраны — GIF (решение создателя бота, 19.10). Его статичные PNG для `/logo`,
`/eminemovna`, `/webhook` (15.10) сохранены как `*.banner.creator.png`.

### Автоматические сообщения

| Ключ | Где | Готов |
|---|---|---|
| `forms.submission.banner` | новая заявка в канале проверки | ✅ |
| `forms.approved.banner` | заявка одобрена: карточка заявки + ЛС заявителю | ✅ шаблон |
| `forms.rejected.banner` | заявка отклонена: то же | ✅ шаблон |
| `forms.public_card.banner` | карточка формы (опубликованная и из меню пака) | ✅ шаблон |
| `select.public_menu.banner` | опубликованное меню ролей | ✅ |

**Шаблоны.** У трёх баннеров бот сам дописывает текст на фон из Figma
(`panel_art/<экран>.base.png`, плейсхолдер скрыт):

- «одобрена/отклонена» — `{ROLE_IN_ENGLISH}`: должность по-английски (бот
  переводит название формы; поправить — в паке формы);
- карточка формы — `{NAME_NO_CAPS}`: название формы строчными, длинное — в две
  строки; надпись сверху («набор! набор!…») — своя у пака, у формы можно задать свою.

Рисует `banner_render.py` шрифтами из `fonts/banner/` (Coolvetica, Dunkin Sans —
положи туда файлы, см. README там). Загрузишь в веб-панели свою картинку вместо
шаблона — бот покажет её как есть, без текста. Поменяла фон в Figma — скажи,
перевыгружу `*.base.png`.

## Дудл-эмодзи для меню форм

Секция «Эмодзи для форм» в Figma: 50 предметов (щит, корона, микрофон…),
`panel_art/emoji/doodle_*.png`, 128×128. При запуске бот заливает их в свои
эмодзи и ставит каждой форме в паке случайный, ещё не занятый. Нарисуешь новые —
добавь компонент `doodle_<имя>` и попроси выгрузить. Список задан в `core.BANNER_SCREENS` (автоматические — в
`core.AUTO_BANNER_SCREENS`). Нужен баннер ещё где-то — скажи, добавлю экран в
список и слот в Figma.

## Как картинки попадают в бота

**Через репозиторий (так сейчас подключены иконки).** PNG лежат в папке
`panel_art/`, в каталоге значение вида `art:thumbnail.embed.png`. Бот отдаёт
их сам по адресу из `WEB_PANEL_URL` (`/art/…`). Новую версию картинки
достаточно заменить файлом и обновить бота — ссылка поменяется сама, Discord
не покажет старую из кэша. Готовые макеты можно просто отдать Claude: он
выгрузит их из Figma и положит в `panel_art/`.

**Через веб-панель.** `/panel` → раздел команды или «Оформление» → у нужного
ключа **Загрузить**. Файл хранится у бота (папка `panel_assets`, можно
поменять через `WEB_PANEL_ASSETS`). Значение из веб-панели перекрывает
значение из репозитория; «Сбросить» вернёт картинку из `panel_art/`.

Если адрес сервера поменяется, ссылки перестроятся сами (для `panel_art/`)
или картинки нужно будет загрузить заново (для загруженных через панель).
Можно также вставить прямую ссылку на картинку с любого хостинга.

## Эмодзи для кнопок

Секция «Эмодзи для кнопок» в Figma: 36 дудлов (`ui_prev`, `ui_next`, `ui_back`,
`ui_add`, `ui_delete`, `ui_save`…), `panel_art/emoji/ui/*.png`, 128×128. Формы
проще и обводка толще — на кнопке они видны размером ~22 px.

При запуске бот заливает их в свои эмодзи и на кнопках панелей меняет обычные
эмодзи на дудлы (соответствие — `ui_emoji.MAP`): стрелки перелистывания,
«Назад», ➕ ➖ 🗑️ ✏️ 💾 и т. д. Кнопки, которые собирают участники в /embed, не
меняются. 
Перерисовала дудл в Figma — скажи Claude, он выгрузит PNG в `panel_art/emoji`.
Дальше бот всё сделает сам: при запуске заметит, что картинка поменялась
(помнит хэш каждого файла), заменит эмодзи в своём хранилище и поправит
сохранённые ссылки на них (кнопки, паки форм). На сервере — `/eminemovna` →
«Эмодзи бота» → «Все» (или только формы / клановые / смайлики / кнопки): новые добавятся,
перерисованные заменятся.

Второй набор — объёмные иконки в фирменных цветах (плоская сторона, наклон в
перспективе и толстый тёмный бок): `panel_art/emoji/ui3d/u3_*.png`, те же 36
имён с префиксом `u3_`. Рисует их `python3 scripts/render_ui3d.py`.

У 50 дудлов форм тоже есть 3D-версии: `panel_art/emoji/doodle3d/d3_*.png`
(`python3 scripts/render_doodles3d.py`). Общий движок — `scripts/art3d.py`
(палитра, наклон, толщина бока).

При запуске бот заливает наборы в свои эмодзи и на кнопках и в меню панелей
меняет обычные эмодзи на свои (соответствие — `ui_emoji.MAP`; кнопкам без своей
иконки достаётся подходящий 3D-дудл): стрелки перелистывания, «Назад», ➕ ➖ 🗑️ ✏️
💾 и т. д. Эмодзи форм в меню паков показываются объёмными. Кнопки, которые
собирают участники в /embed, не меняются. Набор выбирается в веб-панели,
`ui_emoji_style`: `doodle` (по умолчанию — дудлы создателя бота), `3d` или `standard` (обычные эмодзи).
Если объёмная иконка не загрузилась, будет плоский дудл.
Свои стрелки (`nav_prev_emoji` / `nav_next_emoji`) по-прежнему важнее.

Перерисовала дудл в Figma или поменяла иконку в скрипте — скажи: старый эмодзи
в хранилище бота нужно заменить (бот сам заливает только новые имена).

## Смайлики

`panel_art/emoji/smiley/smile_*.png`, 128×128 — фирменные смайлики в 3D.
Девять сделаны прямо из оригиналов (`panel_art/thumbnail.*.png`): рисунок тот
же, добавлены бок, лёгкий наклон и выпуклость. Остальные эмоции нарисованы на
том же пустом лице. Рисует `python3 scripts/render_smileys.py`. Бот их сам не
заливает — набор, чтобы добавить на сервер (Настройки сервера → Эмодзи).

## Аватарка и баннер профиля

`panel_art/profile/` (`python3 scripts/render_profile.py`):

- `avatar_main.gif` — фирменный 2D-смайлик в глюке сменяется 3D и обратно;
  `avatar.png` — статичная (она же в Figma, слот `bot.avatar`);
- варианты: `avatar_spin`, `avatar_moods`, `avatar_bounce`, `avatar_angel`, `avatar_crack`;
- `profile_banner.png` — обычный баннер профиля 680×240 (слот `bot.profile_banner`),
  `profile_banner.gif` — он же анимированный. Слева снизу на баннер ложится
  аватарка — там пусто.

Аватарка 512×512 (Discord обрежет кругом). Ставятся в Developer Portal → Bot.

## Шаблоны новостей — только для создателя бота

`panel_art/news/news.*.png` (20 шаблонов 1200×600, `_all.png` — все на одном
листе) и `scripts/render_news.py`. **Код бота их не использует** — это макеты,
которые создатель бота правит сам. Тесты и бот эту папку не трогают; менять и
перерисовывать можно свободно.

Промо-ролики `promo/*.mp4` и движок `scripts/promo/` — тоже вне бота.
