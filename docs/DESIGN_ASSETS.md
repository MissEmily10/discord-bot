# Оформление бота: картинки для панелей

Каждая панель бота — это embed. У него два места под картинки:

```
┌──────────────────────────────────────────┐
│ ЗАГОЛОВОК                      ┌──────┐  │
│ Текст панели…                  │ ИКОНКА│  │  ← thumbnail: справа сверху
│ Кнопки: …                      └──────┘  │
│ ┌──────────────────────────────────────┐ │
│ │               БАННЕР                 │ │  ← banner: на всю ширину,
│ └──────────────────────────────────────┘ │    под текстом
└──────────────────────────────────────────┘
 [кнопки панели]
```

## Заготовка в Figma

[Discord-бот — оформление панелей](https://www.figma.com/design/oltPivYjeOZWYy40JNYWKp):
все слоты — компоненты нужного размера, названные ключами из веб-панели, с
настроенным экспортом PNG. Справа — живой предпросмотр панели в тёмной и
светлой теме Discord.

## Размеры

| Что | Размер макета | Как показывает Discord | Формат |
|---|---|---|---|
| Иконка (`thumbnail`) | **256 × 256** | до 80 × 80, углы чуть скруглены | PNG с прозрачностью |
| Баннер (`banner`) | **1200 × 300** (4:1) | по ширине embed'а, ~400–520 px | PNG или JPG, до 1 МБ |

- Иконка видна мелко: крупный простой силуэт, без мелкого текста.
- Баннер — «подпись» команды. Важное держи по центру: на телефоне края
  смотрятся меньше.
- Discord бывает тёмный (фон embed'а `#2B2D31`) и светлый (`#F2F3F5`).
  Проверь макеты на обоих фонах; у иконок лучше прозрачный фон.
- Цвет полоски слева у всех панелей — «Основной цвет» в /design или в
  веб-панели. Подбери его под палитру макетов.

## Какие картинки нужны

Достаточно нарисовать по одной иконке (и, по желанию, баннеру) на команду.
Все экраны команды подхватят её сами.

| Ключ в веб-панели | Где видно |
|---|---|
| `thumbnail.default` / `banner.default` | всё, у чего нет своей картинки |
| `thumbnail.embed` / `banner.embed` | /embed, /messages, расписание, триггеры, настройки сообщений |
| `thumbnail.forms` / `banner.forms` | /forms |
| `thumbnail.access` / `banner.access` | /access, /design |
| `thumbnail.buttons` / `banner.buttons` | /buttons |
| `thumbnail.templates` / `banner.templates` | /templates |
| `thumbnail.webhooks` / `banner.webhooks` | /webhooks |
| `thumbnail.select` / `banner.select` | /select |
| `thumbnail.logo` / `banner.logo` | /logo |

Порядок поиска картинки для экрана: своя картинка экрана
(`<экран>.thumbnail`, например `embed.home.thumbnail`) → картинка команды →
общая (`*.default`). `none` на любом шаге — без картинки.

Своя картинка экрана нужна редко: например, отдельная иконка для главного
экрана команды (`embed.home`, `forms.home`, `access.home`…) или «опасная»
иконка для экранов удаления.

## Как загрузить

1. Экспортируй из Figma в PNG (иконки — @1x при фрейме 256 × 256).
2. `/panel` в Discord → открой ссылку → раздел **Оформление**.
3. У нужного ключа нажми **Загрузить** и выбери файл — он сразу сохранится,
   справа появится превью. В разделах команд видно, как выглядит панель.

Файлы хранятся у бота (папка `panel_assets`, в `.env` можно поменять через
`WEB_PANEL_ASSETS`) и отдаются по адресу из `WEB_PANEL_URL`. Если адрес
сервера поменяется, картинки нужно будет загрузить заново. Можно вместо
загрузки вставить прямую ссылку на картинку с любого хостинга.
