# Оформление бота: картинки для панелей

Каждая панель бота — это embed. Картинки встают так:

```
┌──────────────────────────────────────────┐
│                 БАННЕР                   │  ← banner: свой у каждого экрана,
└──────────────────────────────────────────┘    отдельной карточкой НАД текстом
┌──────────────────────────────────────────┐
│ ЗАГОЛОВОК                      ┌──────┐  │
│ Текст панели…                  │ИКОНКА│  │  ← thumbnail: справа сверху
│ Кнопки: …                      └──────┘  │
└──────────────────────────────────────────┘
 [кнопки панели]
```

Discord рисует картинку внутри embed'а только под текстом, поэтому баннер
бот отправляет отдельным embed'ом перед основным.

## Заготовка в Figma

[Discord-бот — оформление панелей](https://www.figma.com/design/oltPivYjeOZWYy40JNYWKp):
все слоты — компоненты нужного размера, названные ключами из веб-панели, с
настроенным экспортом PNG. Справа от иконок — живой предпросмотр панели в
тёмной и светлой теме Discord. Ниже — баннеры всех экранов, по командам.

## Размеры

| Что | Размер макета | Как показывает Discord | Формат |
|---|---|---|---|
| Иконка (`thumbnail`) | **256 × 256** | до 80 × 80, углы чуть скруглены | PNG с прозрачностью |
| Баннер (`<экран>.banner`) | **1200 × 300** (4:1) | по ширине embed'а, ~400–520 px | PNG или JPG, до 1 МБ |

- Иконка видна мелко: крупный простой силуэт, без мелкого текста и без
  белой обводки (на тёмной теме она выглядит рамкой).
- Важное в баннере держи по центру: на телефоне края смотрятся меньше.
- Discord бывает тёмный (фон embed'а `#2B2D31`) и светлый (`#F2F3F5`).
- Цвет полоски слева у всех панелей — «Основной цвет» в /design или в
  веб-панели. Подбери его под палитру макетов.

## Иконки — по командам

Экран без своей иконки берёт иконку команды, а та — общую.

| Ключ | Где видно |
|---|---|
| `thumbnail.default` | всё, у чего нет своей иконки |
| `thumbnail.embed` | /embed и всё внутри (расписание, триггеры, настройки) |
| `thumbnail.library` | главная /library (пока — иконка шаблонов) |
| `thumbnail.templates` | шаблоны в /library |
| `thumbnail.interactive` | главная /interactive (пока — иконка кнопок) |
| `thumbnail.buttons` | наборы кнопок в /interactive |
| `thumbnail.select` | меню ролей в /interactive |
| `thumbnail.forms` | формы в /interactive и /forms |
| `thumbnail.logo` | /logo и стили иконок |
| `thumbnail.eminemovna` | главная /eminemovna (пока — иконка доступа) |
| `thumbnail.access` | доступ и оформление в /eminemovna |
| `thumbnail.webhooks` | вебхуки в /eminemovna |

Для `library`, `interactive` и `eminemovna` своих иконок пока нет — если
нарисуешь, добавлю слоты в Figma и подключу.

Своя иконка экрана (`<экран>.thumbnail`, например `embed.home.thumbnail`)
перекрывает иконку команды. `none` — без иконки.

## Баннеры — по экранам

У каждого экрана свой ключ `<экран>.banner` (например `embed.home.banner`,
`access.users.banner`). Баннер показывается **только** на своём экране:
ничего не подставляется на чужие экраны и не «наследуется» от команды.
Пустой ключ — на экране баннера нет. Полный список экранов — в Figma
(раздел «Баннеры экранов», по 6 командам) и в веб-панели (поле `banner` у
каждого экрана).

## Как картинки попадают в бота

**Через репозиторий (так сейчас подключены иконки).** PNG лежат в папке
`panel_art/`, в каталоге значение вида `art:thumbnail.embed.png`. Бот отдаёт
их сам по адресу из `WEB_PANEL_URL` (`/art/…`). Новую версию картинки
достаточно заменить файлом и обновить бота — ссылка поменяется сама, Discord
не покажет старую из кэша. Готовые макеты можно просто отдать Claude: он
выгрузит их из Figma и положит в `panel_art/`.

**Через веб-панель.** `/panel` → раздел команды или «Оформление» → у нужного
ключа **Загрузить**. Файл хранится у бота (папка `panel_assets`, можно
поменять через `WEB_PANEL_ASSETS`). Значение из веб-панели перекрывает
значение из репозитория; «Сбросить» вернёт картинку из `panel_art/`.

Если адрес сервера поменяется, ссылки перестроятся сами (для `panel_art/`)
или картинки нужно будет загрузить заново (для загруженных через панель).
Можно также вставить прямую ссылку на картинку с любого хостинга.
