# Квесты кланов — принципы и правила

Записано со слов Эмилии (18.10.2026). Списки:
[лёгкие](easy.md) · [средние](medium.md) · [сложные](hard.md) — по 150 уникальных.

## Зачем кланы

Клан — не просто компания друзей. Это объединение, которое **помогает серверу
развиваться** и может **влиять на него**: предлагать, делать, участвовать в
решениях. У каждого клана есть **имя на сервере**: один известен тем, что всем
помогает, другой — сильным составом, третий — ивентами. Кланы разного уровня,
и тем, кто пока «не очень», есть куда расти.

**Активность — по желанию.** Клан может просто платить 5000 за продление, и
никто не обязан выполнять квесты или помогать серверу. Квесты — способ
**заработать стипендию** и имя: не хочешь платить из казны — делай квесты.

## Три уровня

| | Лёгкий | Средний | Сложный |
|---|---|---|---|
| Направление | **внутри** клана | **внутри + снаружи** | **снаружи**, на весь сервер |
| Суть | сплочение, общение, совместный досуг | вместе придумать и сделать что-то для сервера/людей (MVP) | проект от начала до конца, реально нужный серверу |
| Кто | хотя бы половина клана | несколько участников | весь клан |
| Время | 1 час / вечер | несколько дней — 2 недели | 2 недели — 2 месяца |
| Пример | собрание клана на час с отчётом о договорённостях; игра вместе, скрины | обсудить идеи для сервера и одну довести до рабочего наброска | сезон ивентов, наставничество новичков, медиа сервера |

Сферы — любые: игры, творчество, ивенты, «трибуны», категории сервера,
соревнования с другими кланами, медиа, помощь новичкам. Главное — разделение
по уровню (внутри → внутри+снаружи → снаружи) и по длительности.

## Стипендия

За срок (30 дней), начисляется за сутки до продления — **по числу
выполненных квестов** (решено, 18.10; средний без лёгкого тоже считается):

| Выполнено квестов | Стипендия |
|---|---|
| 1 | 1000 |
| 2 | 2500 |
| 3 | 5000 |

Сложный квест — **не дольше месяца**, укладывается в один срок (решено).

## Выдача

- На каждый срок клан получает **ровно по одному квесту каждого уровня**:
  один лёгкий, один средний, один сложный (без выбора — решено).
- Квест, который клан уже выполнял, ему больше не выпадает. Квесты, которые
  выполнили все кланы, уходят из выдачи.
- Сменить выданный квест — товар «Замена квеста» (дёшево).
- Админы добавляют, убирают и правят квесты в панели `.кланквесты`.

## Проверка

Бот видит сам: присутствие в клановых войсах (сколько человек, сколько
времени, кто с включённым микрофоном), сообщения в клановых чатах, новых
участников, респект, награды. Всё остальное подтверждает админ.

1. Клан нажимает **«Сдать квест»**: текст отчёта + скрины/ссылки.
   Бот прикладывает то, что видел сам (например: «в клановом войсе 14 из 22
   человек, 1 ч 12 мин»).
2. Админам приходит **«отмашка»** в канал проверки с кнопками
   **«Принять» / «Вернуть на доработку»** (с комментарием).
3. Принят — отметка в карточке клана, запись в журнал, учёт для стипендии и
   престижа. Возвращён — клан видит комментарий и сдаёт заново.
4. Зависшие проверки (дольше 2 суток) — напоминание админам.

## Престиж

Отдельных уровней славы нет (решено). Престиж — **респекты с направлением**:
принятый квест даёт клану респекты в направлении квеста (указано у каждого).
«Чем известен» клан — направление, где у него больше всего респектов.
