# Шрифты для картинки-предпросмотра

Discord пишет фирменным шрифтом gg sans, но его нельзя распространять, поэтому
предпросмотр (`preview_render.py`) рисуется похожими свободными шрифтами:

- **Inter** (Regular, Italic, SemiBold, SemiBoldItalic, Bold) — текст, заголовки, кнопки.
  Лицензия SIL OFL 1.1, см. `OFL-Inter.txt`.
- **DejaVu Sans Mono** — `код` и блоки кода. Свободная лицензия, см. `LICENSE-DejaVu.txt`.

Файлы урезаны до латиницы, кириллицы и знаков (pyftsubset), чтобы весили меньше.
Эмодзи берутся картинками Twemoji — так же, как их рисует Discord.
