Предпросмотр. Переменные бот подставит при отправке — здесь они подсвечены.

Сохранённые сообщения

Открыть в редакторе, удалить. Сохранённое видно и в /embed → «Мои сохранённые».

Шаблоны

Готовые сообщения сервера. «Использовать» — откроется в редакторе как новое. Сохранить текущее как шаблон — кнопка ниже.

Автоматика сообщения

Переменные

Нажми на переменную — она вставится туда, где стоял курсор в редакторе. Значения бот подставит при отправке.

Шрифты

Твои шрифты лежат на сайте бота — их можно посмотреть и скачать. Этот сайт написан ими.

JSON сообщения

Discohook, webhook builder, Discord API или экспорт бота. «Применить» заменит текущее сообщение.

Настройки сообщения

«Разными» — каждый embed отдельным сообщением (обходит лимит 6000 символов).
